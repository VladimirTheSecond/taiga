## Key design: two Terraform stacks
Since the main stack is destroyed every session, anything that must survive goes into a separate stack:

| Stack | Lifetime | Resources |
|---|---|---|
| `terraform/bootstrap/` | Persistent, applied once | S3 state bucket, Route 53 hosted zone, AWS Budget |
| `terraform/` (main) | Ephemeral, `up`/`down` every session | VPC, EC2, EIP, Route 53 `A` record, generated Ansible inventory |

**Why:** if the hosted zone were destroyed, it would get new name servers on every rebuild, the delegation at the registrar would break, and DNS would need hours to settle. A persistent zone costs ~0.50 USD/month. Also a strong interview point: "I separated long-lived and ephemeral resources."

The bootstrap stack itself keeps local state (chicken and egg: the bucket does not exist before it is created). Optionally migrate it into the bucket afterwards with `terraform init -migrate-state`.

## Risks
- **Let's Encrypt rate limit:** max 5 identical certificates per week. With a rebuild every session that runs out quickly. → Variable `letsencrypt_staging: true` for all test runs, `false` only for the final run. (Later, milestone 2: back up `/etc/letsencrypt` to S3.)
- **DNS propagation of a new domain** can take hours. → Buy the domain **tonight**.
- **SSH host key changes** on every rebuild, sometimes with the same IP. → `StrictHostKeyChecking=accept-new` plus removing the old key in `make up`. Write the trade-off in the decision log.
- **Budget currency:** AWS Budgets works in USD. 20 EUR ≈ 23 USD.

Bugs found and fixed during the session:
- Docker repo added with `deb822_repository` without an apt cache refresh → `docker-ce` not found.
- Makefile relied on `.ONESHELL`, which GNU Make 3.81 (macOS) ignores.
- `certbot --nginx` edits would be overwritten by the next Ansible run → switched to `certonly --webroot`.
- Admin password passed via `docker exec --env` (visible in the process list) → stdin.
- `taiga-async` crash loop: `RABBITMQ_USER/PASS` missing.
- Attachments and static files → 404: added host bind mounts, Nginx + `taiga-protected` with `X-Accel-Redirect`.
- `make check` failed right after a rebuild because macOS cached NXDOMAIN (Route 53 negative TTL 900 s) → check now connects to the Terraform IP.
